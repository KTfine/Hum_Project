# 真人拍照指导的评估标准

这些标准用于设计和判断后续真人实验，不表示当前模型已经通过，也不自动写入提示词。历史失败记录见 [真人指导实验](../validation/2026-11-06-photo-guidance.md)。

## 方向与坐标

给真人的方向建议以被拍摄者自身左右为基准，明确说“你自己的左边 / 右边”。用户未指定坐标系的“我想往左一点”也按其自身左边理解；若明确要求照片或画面某侧，应将构图目标转换为人的动作方向。角色内部 x/y 是画面坐标，不能与真人左右混用。

朝向和镜像参与判断：未镜像且正对镜头时，人的左对应画面右；背对镜头时，人的左对应画面左。侧身、朝向或镜像状态不明确时先确认。自拍不自动等于镜像，没有软件翻转也不证明设备未镜像。

可以让用户确认一次“本人向左时预览往哪边”，作为会话信息沿用；朝向或镜像改变后重新确认。当前会话重建会清空旧上下文，不能假定这项信息会自动继承。

## 连续指导

在真实构图目标下观察完整过程：理解目标、给出建议、观察实际移动后的画面、继续纠正、到位后停止。分别记录用户意图、真人实际位置和模型判断，不能用一句“已到位”代替画面证据。

静态单帧、预制素材、合成语音和角色位移检查分别报告，不能代替真人连续调整验收。每轮仍只修改用户指定的一个提示词问题。
