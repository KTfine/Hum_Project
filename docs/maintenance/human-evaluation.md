# 真人拍照指导评估

2026-11-07 起的测试设计。以下不是已通过的结论，不引用此前实验，也不自动增加 prompt 规则。

## 指导模式

- 确认预览和模型输入没有虚拟角色。记录用户拍摄目标、人物朝向、镜像状态，以及“左 / 右”指本人还是画面；含义未明确时不直接判断方向对错。
- 分别检查场景观察、构图、姿势和表情建议是否符合用户目标。标签有效不代表建议正确，角色位移不代表真人移动。
- 连续过程覆盖初始画面、未执行建议、按建议调整、反方向调整、到位和撤回目标；观察模型是否依据新画面判断、到位后停止纠正。
- 模式切换会清空模型上下文，跨模式测试记录目标和方向信息是否重新提供，不假定已经继承。

## 合照模式

- 分别验证邀请生成 mode 标签、成功加载会话、立绘小窗、实际动作和互动内容；一个环节通过不代表全部通过。
- 区分请求真人调整与请求角色移动；按用户意图判断 move / scale / rotate / tachie，不按动作条数判断质量。
- 覆盖否定、取消、聊天、重复邀请和返回指导。无动作也可能正确，不强制每轮保持标签。
- 当前没有同框照片合成或保存功能，不能按已实现能力验收。

## 证据范围

合成图片标注为合成图文实验，合成语音标注为重放，模拟连接和静态图像单独报告。真实连续摄像头 / 麦克风与实际人的调整才属于真人实时闭环。记录样本数、失败、无回复、原始输出和真实位置变化；短测不表述为长期稳定。
