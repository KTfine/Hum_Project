# 当前维护约定

这里管理仍有用的工程与实验约定，供人和开发工具共同阅读。它们不自动注入模型；模型实际收到的内容由 prompt.py 与 build_control_prompt 决定。用户的新实验指令可以调整研究方案，修改时同步记录原因和结果。

## 保留的约定

- 保留真人拍照指导与伙伴合照两条目标，分别验收；角色动作成功不代表真人指导有效。
- 保留共用规则 + 两种模式模板、默认指导，以及模型标签驱动的会话重建。动作信息只放合照模板；模式不作为客户端动作权限。详细行为以 [模式说明](../modes-and-prompts.md) 为准。
- 保留单行多标签和完整标签闭合后的流式增量执行，允许跨分块。调整协议时保留参数校验，区分真人动作与角色画面坐标。
- 人工提示词实验每轮只处理一个明确问题，展示修改前后差异，记录基线、输入、原始标签、文字适配、实际动作及未验证项。未执行不记为通过，模拟或静态素材不称为真人闭环。
- 按改动范围运行相关检查，更新 CHANGELOG，并按独立目的提交。上传前核对差异，上传后核对远端提交和检查结果，不覆盖他人的提交。
- 保留第三方固定版本、来源和可审查补丁。凭据、私人图像或录音、原始会话日志、模型权重、本机环境不提交；公开仓库只记录必要实验摘要。

真人左右方向、镜像关系和连续指导的验收标准单列在 [真人指导评估](human-evaluation.md)，不据此未经实验就向 prompt 叠加要求。

## 本次审查与整理

| 原内容 | 处理 | 原因 |
|---|---|---|
| 流式协议、状态准确性、实验真实性、数据与版本管理 | 保留在本目录 | 仍影响正确性和结果可追溯性 |
| 两种模式、画面和 prompt 组装细节 | 移到程序说明 | 属于当前实现，适合人直接阅读，无需在多个文件重复 |
| 真人左右、朝向、镜像、连续目标 | 移到评估文档 | 是后续真人验证的判据，不是本轮已验证结论 |
| 强制每轮 move / hold、固定询问、ON/OFF 动作权限、独立动作诊断 | 不作为现行约定 | 已被用户要求撤销；仅在历史实验中说明当时条件 |
| 固定不许增加示例等提示词写法 | 不作为永久规则 | 后续由用户指定单项实验，不预先限定实验手段 |
| 旧计划要求调用特定 AI 技能或子代理 | 删除执行要求，归档计划 | 已不适用于当前工作，不应继续触发额外流程 |
| 两份重复、但适用部署入口不同的 API 手册 | 合并为一份当前参考 | 区分 cloud / Slurm 监听地址，统一本机 18006 隧道示例 |
| 根目录命令清单和来源说明 | 合并入口 / 移到 reference | 减少重复入口，固定来源仍保留 |

根目录保留短 AGENTS.md，是为了让后续工具能发现这里；无需把全部限制继续堆在仓库首页。本次不修改 prompt、客户端、协议、后端运行代码或启动路径。
